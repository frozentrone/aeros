Hover over the plot for values. D10, D50 and D90 are calculated by cumulative summation of the normalized discrete volume fractions, followed by linear interpolation of particle size at 10%, 50% and 90%. D[4,3] is the volume-weighted mean diameter, Σ(vᵢdᵢ)/Σvᵢ. D[3,2] is the Sauter mean diameter, Σvᵢ/Σ(vᵢ/dᵢ), using the normalized volume fractions. SSA is the PSD-derived external geometric surface area for non-porous spherical particles: SSA = 6,000,000/(ρ × D[3,2]), with ρ in kg/m³ and D[3,2] in µm, giving m²/kg. It is not BET SSA. This is a numerical summary of the imported distribution, not a correction or model fit.

Upper-tail correction

Particle density: inherited from the PSD plots tab and used for PSD-derived equivalent spherical specific surface area. Enter true particle density, not bulk or tapped density.
Strict tail cap: at 100% strength, every target bin above the crossover is capped at the reference value. No partial transition is applied above the crossover.
Shifts the complete target volume-density distribution left by one measured particle-size class at a time. The coarse end is zero-filled and any volume shifted below the smallest class is retained in the smallest class. Shifting stops when target minus reference is not positive above the automatic crossover, within the selected tolerance.
Normalization and D-values: each imported PSD is scaled so its discrete volume fractions sum to exactly 100%. The app then cumulatively sums those normalized fractions and linearly interpolates particle size at 10%, 50% and 90%. The original raw sum is retained in the correction report and CSV audit fields.
Interpretation: this is a user-directed artefact correction, not a validated reconstruction of the true PSD. Keep the original data and correction settings with any exported result.
Automatic crossover: the last sign change in target minus reference that precedes a sustained upper-tail excess. Above it, excess over the interpolated reference is reduced by the selected strength. At 100% strength, the corrected target cannot exceed the reference at any sampled size above the crossover.

PSD-derived SSA: calculated assuming non-porous spherical particles using the volume distribution: SSA = (6,000,000/ρ) × Σ(vᵢ/dᵢ)/Σvᵢ, with ρ in kg/m³ and d in µm. This is an equivalent external geometric surface area and is not BET SSA.
Debris-size estimate: below the correction crossover, the interpolated reference PSD is subtracted from the corrected target PSD. Only positive differences are retained. Average debris size is the difference-volume-weighted mean, Σ[dᵢ·max(vcorrected,i−vreference,i,0)] / Σ[max(vcorrected,i−vreference,i,0)]. Because every PSD is normalized to 100%, the positive-difference sum is reported as volume of debris (% of the normalized PSD volume).

Row order: the reference PSD is fixed first. Corrected targets follow the PSD Correction table order and can also be reordered here. Edited dispersion pressures remain attached to their PSD rows, and CSV export follows the displayed order.
Calculation: D[4,3] is calculated from each normalized reference or corrected volume distribution as Σ(vᵢdᵢ)/Σvᵢ. The correlation is evaluated for every row using dp = D[4,3] of the reference PSD. Corrected target rows still display their own corrected D[4,3] for comparison. The SSA column shows the PSD-derived SSA of each transferred distribution using the current density; for corrected targets this is corrected SSA. Relative SSA change is reported only as the dimensionless fraction ΔSSA/SSA₀ = (SSAᵢ − SSA₀)/SSA₀, where SSA₀ is the reference PSD SSA. P is converted from the editable gauge pressure to absolute pressure using P = Patm + Pgauge.
